# Statistics and figures

## Tables

- **Analyze > Statistics…** (Ctrl+T): counts, frequencies and intensity statistics per gate and sample.
- **Analyze > Frequencies…**: population frequencies across samples, with an export laid out for graphing programs.
- **Analyze > Expression…**: each channel's expression across samples.
- **Analyze > Group comparison…**: each population compared between groups, with p-values adjusted by Benjamini-Hochberg.
- **Analyze > Absolute counts…**: cells per microlitre from counting beads.

Every table can be copied to the clipboard or exported as CSV.

## Plots and figures

- **File > Export plot image…** saves the current plot as PNG, SVG or PDF; **File > Copy plot to clipboard** copies it for a slide.
- **Tools > Quick figure grid…** builds a grid of plots across samples.
- **Tools > Layout editor (beta)…** arranges plots, statistics and charts on a page for a figure.
- **Tools > Gating tree diagram…** draws the gating strategy.

## Reports

**File > Analysis report (HTML)…** writes the gates, plots and statistics as one HTML page. **Analyze > Methods & provenance…** writes a methods paragraph and the settings used, and **Analyze > History / audit…** lists every change made in the session.
