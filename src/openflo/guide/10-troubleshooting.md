# Troubleshooting

## A window or button is cut off

OpenFlo fits its windows to the screen; at very high display scaling, windows scroll instead. **View > Dock all panels** puts floating panels back.

## A number reads NA

NA means the value cannot be computed: the gate's channel is missing in that sample, its parent is empty, or a model could not be fitted. It is never a zero.

## Files will not load

Check the file in **Tools > FCS inspector…**. **View > Show log / console** shows what the loader reported.

## Something else

**Help > Report a problem…** gathers the details a bug report needs. **Help > Online documentation** opens the documentation on the web, when you are connected.
