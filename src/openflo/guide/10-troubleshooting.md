# Troubleshooting

## A window or button is cut off

OpenFlo fits its windows to the screen; at very high display scaling, windows scroll instead. **View > Dock all panels** puts floating panels back.

## A number reads NA

NA means the value cannot be computed: the gate's channel is missing in that sample, its parent is empty, or a model could not be fitted. It is never a zero.

## Files will not load

Check the file in **Tools > Files & checks > FCS inspector…**. **View > Show log / console** shows what the loader reported.

## Something else

**Help > Report a problem…** sends a bug report or an idea to the developers through getopenflo.com, with no account needed. Tick **Attach the error report** to add OpenFlo's error report, in which file paths, sample names and emails are replaced by tokens; **Show what is sent** shows the exact text first. **Help > Online documentation** opens the documentation on the web, when you are connected.
