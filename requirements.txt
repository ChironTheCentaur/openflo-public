# OpenFlo runtime dependencies.
# Pin to the versions known to work together in the .venv this repo ships with.
#
# These pins are INTENTIONALLY tighter than pyproject.toml's dependency ranges,
# and the two are meant to diverge: pyproject declares what OpenFlo is
# COMPATIBLE with (so it can coexist in a user's environment), this file
# reproduces the exact stack it is TESTED against.
# When a pin here and a range there disagree, that is by design, not drift.
# Bump intentionally; flow-cytometry math is sensitive to numpy/scipy/sklearn
# major changes.
#
# The Windows installer bundles exactly these, so every package it ships is
# pinned here, dependencies of dependencies too: scripts/build_windows_installer.py
# stops when it stages one that has no == pin.
#
# Install:
#   python -m venv .venv
#   .venv\Scripts\activate                  (Windows)
#   source .venv/bin/activate               (macOS / Linux)
#   pip install -r requirements.txt
#
# Python 3.11+ required (uses contextlib.chdir, PEP 604 unions, typing.Literal).
